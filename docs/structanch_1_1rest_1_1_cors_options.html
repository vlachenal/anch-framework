Detailed Description

Cross-Origin Resource Sharing (CORS) options, set with Api::cors .

Allowed methods are not configured: they are the methods of the routes matching the request path (HEAD with GET , and OPTIONS ).

api.cors({
.origins = {"https://app.example.com"},
.headers = {"Content-Type", "Authorization"},
.exposedHeaders = {"Location"},
.credentials = true,
.maxAge = std::chrono::hours(1)
});
