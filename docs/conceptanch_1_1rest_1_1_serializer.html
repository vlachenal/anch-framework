Detailed Description

Codec which serializes T values.
A codec is a type with static functions:

  • mediaType() : the media type it handles
  • serialize(const T&, std::ostream&) : write value
  • deserialize(T&, std::istream&) : read value (Deserializer ). Errors are reported with exceptions.

Codecs can also have serialize(const T&, std::ostream&, anch::rest::Side) and deserialize(T&, std::istream&, anch::rest::Side) functions: server and client use them when they are defined (see anch::rest::serializeBody and anch::rest::deserializeBody ).
