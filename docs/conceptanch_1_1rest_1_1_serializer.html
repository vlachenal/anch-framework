Detailed Description

Codec which serializes T values.
A codec is a type with static functions:

  • mediaType() : the media type it handles
  • serialize(const T&, std::ostream&) : write value
  • deserialize(T&, std::istream&) : read value (Deserializer ). Errors are reported with exceptions.

Codecs can also have richer functions (one serialize / deserialize form is enough), which server and client use when they are defined (see anch::rest::contentTypeOf , anch::rest::serializeBody and anch::rest::deserializeBody ):

  • contentType(const T&) -> MediaType : Content-Type of the serialized value, computed before serialization (a multipart codec adds its boundary parameter) ;
  • serialize(const T&, std::ostream&, anch::rest::Side) or serialize(const T&, std::ostream&, const anch::rest::MediaType&, anch::rest::Side) : the media type is the one returned by contentType() ;
  • deserialize(T&, std::istream&, anch::rest::Side) or deserialize(T&, std::istream&, const anch::rest::MediaType&, anch::rest::Side) : the media type is the Content-Type of the body, with its parameters ( charset , boundary , ...) ;
  • stream(const T&, const anch::rest::MediaType&, anch::rest::Side) -> BodyStream : client sends the stream instead of serializing the value in memory.
