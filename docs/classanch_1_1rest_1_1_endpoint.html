Detailed Description

template<typename F>
class anch::rest::Endpoint< F >

Endpoint function bound to a route.
Function arguments are, in order:

  • const anch::rest::Request& (optional)
  • path parameters, in pattern order (types supported by ParamConverter , 400 when invalid)
  • Body (optional): deserialized with the codec matching Content-Type (415 when not consumed, 400 when missing or invalid)

Function result:

  • Response : sent as is
  • void : 204
  • std::optional<T> : 404 when empty, T otherwise
  • T : serialized with the codec negotiated with Accept (406 when not acceptable)
