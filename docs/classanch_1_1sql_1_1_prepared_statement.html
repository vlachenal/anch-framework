Detailed Description

SQL prepared statement.

Prepared statements are created and cached by Connection::prepareStatement . Parameters are numbered from 1 ; every parameter has to be bound before execution (values are kept between executions).
The number of parameters is given by the database driver (MySQL and SQLite count them on the server side, PostgreSQL '?' placeholders are found with findPlaceholders and replaced by $n ).
Errors are reported to the connection: a fatal error invalidates it (see Connection::isValid ).
