Detailed Description

AnCH unit tests library namespace.

A test executable implements anch::ut::setup to register its tests; assertions are anch::ut::assertThat and anch::ut::assertTrue . See AnCH unit tests library documentation.

template<typename... T>
void anch::ut::assertThat ( bool check,
std::type_identity_t< anch::ut::AssertMessage< T... > > message,
const T &... args )

Assert clause with error message formatting (std::format syntax with {} placeholders).
The message is checked at compile time (it has to be a string literal whose placeholders match the arguments) and is formatted only when the assertion fails. The assertion location is reported with the message.
