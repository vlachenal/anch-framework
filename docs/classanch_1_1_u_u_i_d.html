Detailed Description

UUID generator and parser.

See RFC 4122 for more details (http://www.ietf.org/rfc/rfc4122.txt)

This class needs anch-crypto and anch-device libraries.

◆ randomTime()

UUID anch::UUID::randomTime ( )
static

Generate a new UUID with version 7 (random + time) algorithm.
A 16 bits counter (RFC 9562 section 6.2, method 1) is written in the 12 rand_a bits and in the 4 first rand_b bits: UUID generated by this process are strictly increasing (string and binary order), including between threads. It is initialized randomly on each new millisecond (at least 32768 UUID per millisecond before timestamp is incremented). The 58 last bits are random.

Returns
the new UUID

◆ toChars()

char * anch::UUID::toChars ( char * first) const

Write UUID string representation without allocation.
Exactly STRING_SIZE lowercase hexadecimal characters and '-' are written (no '\0' ). Each part is written with its fixed width: higher bits of a part which does not fit (which can only be set with the parts constructor) are ignored.

Parameters
firstthe first character to write (at least STRING_SIZE characters available)
