Detailed Description

application/x-www-form-urlencoded codec for Form (fields only).

Values are written with the WHATWG URL-encoded serializer (space is + ). On reading, + is a space, empty pairs are ignored and a pair without = is a field with an empty value. Content is UTF-8: another charset is refused.

Types with a FormMapper are read and written through a Form .

api.post("/login", [](anch::rest::Body<anch::rest::Form> form) {
std::string user = anch::rest::requiredFormField<std::string>(*form, "user");
...
}).consumes<anch::rest::FormUrlEncoded>();
client.post("/login").body<anch::rest::FormUrlEncoded>(anch::rest::Form().add("user", "rex")).send();
