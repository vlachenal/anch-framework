Detailed Description

template<anch::Validable T, typename C, std::shared_ptr< T >(*)(const C &) make_ptr = std::make_shared<T>>
class anch::ResourcePool< T, C, make_ptr >

Generic resource pool utility class.

Maximum number of resources is mandatory.
Intialize pool size will instanciate resources for imediate use.
Resources will be instanciated with their configuration, outside the pool lock.
If no resource is available, pool will wait until timeout (default to 100ms) is reached.
Resources are automatically released through their destructor: release() is called on resources which implement it (Releasable), then invalid resources are destroyed and will be replaced on demand.
If you have only one action to do, you can use pool.borrowResource().get().doAction() ; otherwise you should to keep anch::PoolableResource until all actions have been done (with auto res = pool.borrowResource()).
Borrowed resources can outlive their pool: they will be destroyed when released.
You can specifiy an std::shared_ptr creation function as third template parameter. By default, std::make_shared<T> will be used. It can be usefull for polymorphism dynamic allocation.
