Detailed Description

Network socket (POSIX).

A Socket owns its file descriptor: it is closed by the destructor. Sockets can be moved, not copied.
Every method raises IOException with the errno value on error. Interrupted system calls (EINTR ) are restarted. SIGPIPE is not raised when peer has closed the connection: send raises IOException (EPIPE ) instead.
For TCP connections, TcpStream and TcpServer provide a stream interface ; for UDP, UdpSocket .
