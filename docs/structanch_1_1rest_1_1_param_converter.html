Detailed Description

template<typename T>
struct anch::rest::ParamConverter< T >

Path parameter converter: customization point to bind path parameters to endpoint arguments.
A specialization provides static std::optional<T> convert(std::string_view value) , which returns an empty value when the parameter is invalid (the response is 400 ).
Integral and floating point types, bool , std::string and anch::UUID are supported.
