Detailed Description

Media type (RFC 9110): type/subtype with parameters.
Type, subtype and parameter names are stored in lower case. In Accept header, the q parameter is the quality and is not kept in parameters.

std::vector< anch::rest::MediaType > anch::rest::MediaType::parseAccept ( std::string_view value)

Parse Accept header value.
Media ranges are sorted by quality (highest first, stable). Invalid media ranges are ignored. Media ranges with q=0 are kept: they exclude the media types they include (see negotiate).
