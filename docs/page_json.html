AnCH JSON library documentation

Introduction

AnCH JSON library is JSON serialization and deserialization library for JSON format.

Prerequisites

AnCH JSON is a standalone library.

Installation

CMake target anch::json:

find_package(Anch REQUIRED)
target_link_libraries(my-app PRIVATE anch::json)

See installation.

Conception

Serialized fields are declared by specializing anch::json::registerObject for each type: fields are registered with their JSON key and their member pointer (or a getter function). Containers and std::optional fields give their value type as template argument.

anch::json::serialize writes JSON in a stream or returns a string ; anch::json::deserialize reads a stream and raises anch::json::MappingError on invalid JSON (with its position). Mapping options (anch::json::MappingOptions ) control unknown fields, null values and limits (depth, payload size).
With ANCH_UUID and ANCH_DATE options, anch::UUID , anch::date::Date and std::chrono::year_month_day are mapped as strings (RFC 3339 for dates).

Examples

#include "json/json.hpp"
#include <iostream>
#include <optional>
#include <sstream>
#include <string>
#include <vector>
struct Pet {
uint64_t id;
std::string name;
std::vector<std::string> tags;
std::optional<std::string> owner;
};
// Declare serialized fields (once per type)
template<>
void
anch::json::registerObject(anch::json::ObjectMapper<Pet>& mapper) {
mapper
.registerField("id", &Pet::id)
.registerField("name", &Pet::name)
.registerField<std::string>("tags", &Pet::tags) // container: element type is given
.registerField<std::string>("owner", &Pet::owner); // std::optional: value type is given too
}
int
main() {
Pet pet{1, "Rex", {"dog", "good boy"}, std::nullopt};
std::string json = anch::json::serialize(pet);
std::cout << json << std::endl;
std::istringstream input(R"({"id":2,"name":"Médor","tags":["cat"],"owner":"Vincent"})");
Pet parsed = anch::json::deserialize<Pet>(input); // anch::json::MappingError when invalid
std::cout << parsed.name << " " << parsed.owner.value_or("-") << std::endl;
return 0;
}
