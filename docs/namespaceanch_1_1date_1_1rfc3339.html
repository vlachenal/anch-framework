Detailed Description

RFC 3339 dates formatting and parsing.

RFC 3339 (https://www.rfc-editor.org/rfc/rfc3339#section-5.6) defines:

  • date-time : YYYY-MM-DDTHH:MM:SS[.fraction](Z|+HH:MM|-HH:MM) (a point in time), mapped to anch::date::Date ;
  • full-date : YYYY-MM-DD (a calendar day without time zone), mapped to std::chrono::year_month_day .

These are the date-time and date formats of JSON schema and OpenAPI.
Parsing follows the RFC grammar: T and Z can be lower case ; the space separator allowed by the RFC note is refused ; fraction can have any number of digits (digits after the nanosecond are truncated) ; offset -00:00 (unknown local offset) is read as UTC ; leap second ( 60 ) is accepted at 23:59 UTC only, and is read as the next second (time points have no leap seconds).
Functions are thread safe.
