◆ getPath()

const std::string & anch::json::MappingError::getPath ( ) const

Path of the value in error getter.
The path is a JSON Pointer (RFC 6901) from the deserialized root value: /pets/3/name for the name field of the fourth item of the pets array. It is empty when the error is not in a field or array item value (root value, field name or separator).
When path is not empty, what() message starts with the path followed by ": " .

Returns
the path
