Detailed Description

Network interfaces.

Network interfaces are listed with getifaddrs : every interface is listed, with or without IP address, with its IPv4 and IPv6 addresses. They are loaded on first access and kept until reload .
Interfaces are returned by copy: a reload does not invalidate what has been retrieved before, and every method can be called concurrently.
