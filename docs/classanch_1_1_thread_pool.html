Detailed Description

Thread pool utility class.

The pool runs a fixed number of worker threads which execute the queued tasks. Number of threads can be parameterized in constructor. If not set, it will be equal to the number of processors (or 1 if it can not be detected).

Tasks are queued with add and executed once the pool has been started with start. Exceptions thrown by tasks are ignored.

stop and awaitTermination must not be called from a task (they wait for running tasks).
The destructor drops queued tasks and waits for running ones.

◆ awaitTermination()

template<typename R, typename P = std::ratio<1>>
void anch::ThreadPool::awaitTermination ( std::chrono::duration< R, P > duration)

Await thread pool termination.
Wait for queued tasks execution until duration is reached. Then queued tasks which have not been started are dropped, running tasks are awaited (they can not be interrupted) and the pool is stopped.
If the pool is not started, queued tasks are dropped.
New tasks are rejected while awaiting termination.

Parameters
durationthe maximum duration to wait for queued tasks. If <1 wait indefinitly.
