Detailed Description

Network namespace.

Network sockets as C++ streams (POSIX only, IPv4 and IPv6):

  • anch::network::TcpStream : a TCP connection as a std::iostream ;
  • anch::network::TcpServer : accept connections as anch::network::TcpStream ;
  • anch::network::UdpSocket : UDP datagrams ;
  • anch::network::Socket and anch::network::Address : RAII socket and resolved address used by the classes above.

Errors are reported with anch::network::IOException (a std::system_error with the errno value).
