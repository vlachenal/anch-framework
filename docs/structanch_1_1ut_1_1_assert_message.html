Detailed Description

template<typename... T>
struct anch::ut::AssertMessage< T >

Assertion message with its location.

Format string of assertThat : the format string is checked at compile time against the arguments types (as std::format does) and the location of the call is captured.
It is built implicitly from a string literal ; it should not be used directly.
