Detailed Description

Log file writer.

Manage file writer with file rotation on size.

Configuration:

  • path: the log file path (mandatory ; its directory has to exist) ;
  • max-size: maximum file size before rotation, in bytes, with optional unit K, M, G or T (powers of 1024). No rotation when not set ;
  • max-rotate-files: number of archives to keep (<path>.0 is the most recent). Default to 1. With 0, the file is truncated on rotation.

File system errors during rotation are ignored: the current file is kept and rotation is tried again later.
