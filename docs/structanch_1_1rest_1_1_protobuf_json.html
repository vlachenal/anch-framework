Detailed Description

application/json codec for protoc messages: Protocol Buffers JSON mapping (field names in lowerCamelCase, 64 bits integers as strings, ...). Unknown fields are refused on server side and ignored on client side (server responses are trusted). Invalid messages raise std::invalid_argument ( 400 on server side).
