Detailed Description

RPC service: unary methods of a Protocol Buffers service, served by installRpc (Connect and gRPC-Web in Api , HTTP/1.1) and by GrpcServer (gRPC, HTTP/2) with the same handlers.

anch::rest::RpcService service("pets.PetStore");
service.unary<pets::GetPetRequest, pets::Pet>("GetPet", [](const pets::GetPetRequest& request, anch::rest::RpcContext&) {
if(request.id() != 1) {
throw anch::rest::RpcError(anch::rest::RpcCode::NOT_FOUND, "no pet");
}
pets::Pet pet;
pet.set_id(1);
return pet;
});
anch::rest::installRpc(api, service); // POST /pets.PetStore/GetPet

Handler errors: RpcError is sent with its code and message, HttpException with the code of its status ( 400 is INVALID_ARGUMENT , 404 is NOT_FOUND , ...), other exceptions are INTERNAL without message.

Methods have to be declared before calls; calls can then be made from several threads.
