Detailed Description

Date part formatter interface.

Implement this interface to add a pattern to DateFormatter (DateFormatter::registerFormatterPart ). Protected accessors give access to Date fields.
A part has a fixed size: setValue receives exactly getSize characters. When a Date is parsed, its fields are set to 1970-01-01 00:00:00.000 before parts are called, and the timestamp is computed afterwards.
