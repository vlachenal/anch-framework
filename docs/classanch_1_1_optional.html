Detailed Description

template<typename T>
class anch::Optional< T >

std::optional usefull methods.

Provides some missing (from my point of view) features to std::optional .
Every std::optional constructor and method is available. Assignments use these constructors.
Since C++23, std::optional provides transform , and_then and or_else which cover map and ifValueOrElse use cases.
