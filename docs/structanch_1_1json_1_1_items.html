Detailed Description

template<typename... C>
struct anch::json::Items< C >

Items constraints.

Constraints are checked on every item of a collection or every value of a map. Error path contains the item index or the map key.

mapper.registerField<std::string>("tags", &Pet::tags, anch::json::maxItems(10), anch::json::items(anch::json::minLength(1)));
