Detailed Description

template<anch::Validable T>
struct anch::ResourcePoolState< T >

Resource pool shared state (internal usage).

State shared between ResourcePool and its borrowed PoolableResource.
It is kept alive by borrowed resources: a resource can be released after its pool destruction.
Every member is protected by _mutex.
