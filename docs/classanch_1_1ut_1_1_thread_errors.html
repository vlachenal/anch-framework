Detailed Description

Exceptions raised in threads started by a unit test.

An exception (as a failed assertion) raised in a thread other than the test one can not be caught by the runner: the process is terminated (std::terminate ) without any report.
Wrap thread functions with wrap : the first exception raised in a wrapped function is kept, and it is raised again in the test thread by rethrow once threads have been joined.

anch::ut::ThreadErrors errors;
std::thread thread(errors.wrap([]() {
anch::ut::assertThat(check(), "check failed in thread");
}));
thread.join();
errors.rethrow(); // the failed assertion is reported by the runner
