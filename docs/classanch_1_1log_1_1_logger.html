Detailed Description

Logger class.
Aims to provide logging facilities.

Logging levels are:

  • TRACE
  • DEBUG
  • INFO
  • WARN
  • ERROR
  • FATAL
Author
Vincent Lachenal

◆ write()

void anch::log::Logger::write ( const anch::log::Level & level,
const std::string & message ) const
noexcept

Write an already formatted message on every writer.
The level is not checked: check it with isEnabled before formatting the message.
Writer errors are ignored: a writer error does not prevent other writers to log.
