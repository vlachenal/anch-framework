Detailed Description

Thrift transport over an anch-rest client (header only: link anch::rest-client ): calls are sent with POST path on client base URL (client filters, authentication and transport apply), to an API with installThrift or any Thrift HTTP server. Clients generated by thrift –gen cpp use it as is:

auto transport = std::make_shared<anch::rest::ThriftTransport>(client, "/thrift/pets");
pets::PetStoreClient pets(anch::rest::thriftProtocol(anch::rest::ThriftProtocol::BINARY, transport));
pets::Pet pet;
pets.getPet(pet, 1);

The protocol given to the transport sets the request content type (it has to be the one of the client protocol). Responses with status greater or equal to 400 raise HttpError . A transport is used by one client at a time.
