Detailed Description

gRPC server (HTTP/2) for RpcService : the same services can be installed in an anch-rest API ( installRpc , Connect and gRPC-Web) and in a gRPC server, for native gRPC clients (stubs generated by grpc_cpp_plugin ).

anch::rest::GrpcServer server;
server.addService(service).listen("0.0.0.0:50051");
server.start();
// ...
server.shutdown();

Methods are unary: the first request message is processed. RpcError is sent with its code and message ( UNIMPLEMENTED for unknown methods), request metadata are given in RpcContext , response metadata are sent as initial metadata. Services have to outlive the server.
