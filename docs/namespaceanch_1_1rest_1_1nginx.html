◆ handle()

int anch::rest::nginx::handle ( void * app,
const anch_rest_request_t * request,
const anch_rest_response_writer_t * writer )
noexcept

Handle request with API (see anch::rest::Api::handle ). Unknown methods are answered with 501 , errors with 500 .

The request body is read in stream (anch::cutils::CIStream on the module reader): it is read while nginx receives it. The response body is written in stream (anch::cutils::COStream on the module writer, blocks of writer->buffer_size bytes): the response is started when the first block is full, with chunked transfer encoding, or at the end of the body with its length when it fits in one block. An error raised before the start is answered with 500 , an error raised after interrupts the response.
The request outlives the response body writing: a body writer can read the request body (echo, ...).

requestthe request
writerthe response writer
Returns
0 when response is complete, -1 when it has been interrupted after its start
