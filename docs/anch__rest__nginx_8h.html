Detailed Description

AnCH REST nginx module C ABI.
An application is a shared library which exports anch_rest_application (see ANCH_REST_APPLICATION in rest/nginxApplication.hpp ). The nginx module loads it with dlopen , creates one application per worker process, and calls handle from nginx thread pool threads (or from the event loop when thread pool is disabled).

Request and response bodies are streamed: the application reads the request body with anch_rest_body_reader_t and writes the response with anch_rest_response_writer_t . In a thread pool, these functions block until nginx has received or sent data.
