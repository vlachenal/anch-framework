Detailed Description

Form part: a field ( text/plain by default) or a file (with a file name, application/octet-stream by default).

Content is in memory or in a file ( fromFile , fromTemporaryFile , large parts read by Multipart ). It is read with open (stream) or with content , which loads a file content in memory on first call: use open for files. Copies of a part share its file.
