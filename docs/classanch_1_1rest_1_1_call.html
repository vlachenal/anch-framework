Detailed Description

template<typename... Codecs>
class anch::rest::Call< Codecs >

Request being built by Client .
Accepted codecs are part of the type: accept adds a codec and as deserializes the response with the accepted codec matching its Content-Type :

Pet pet = client.get("/pets/{id}", 42).accept<anch::rest::Json>().as<Pet>();

A call is sent once: send , execute and as are called on rvalues.
