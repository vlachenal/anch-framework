Detailed Description

Required field constraint.

The field has to be present in JSON object, otherwise anch::json::MappingError is raised with MISSING_FIELD error code.
null value is accepted only when the field can hold it ( std::optional , std::shared_ptr , std::unique_ptr or pointer): otherwise anch::json::MappingError is raised with CONSTRAINT_VIOLATION error code.

mapper
.registerField("id", &Pet::id, anch::json::required)
.registerField<std::string>("owner", &Pet::owner, anch::json::required); // std::optional: present, can be null
