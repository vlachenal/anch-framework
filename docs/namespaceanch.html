◆ convert()

template<anch::Convertible N>
N anch::convert ( std::string_view str)

Performs strict conversion from string to number.

The whole string has to be a number: leading or trailing characters (including spaces and '+' sign) are rejected.
The conversion does not depend on locale. Negative values are rejected for unsigned types and out of range values are rejected. int8_t and uint8_t are converted as numbers (not as characters).
Floating point values can be written in fixed or scientific notation, and can be inf or nan.

Parameters
strthe string to convert
Returns
the number
