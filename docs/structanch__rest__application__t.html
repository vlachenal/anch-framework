int(*) anch_rest_application_t::handle(void *app, const anch_rest_request_t *request, const anch_rest_response_writer_t *writer)

Handle request (thread safe). The response is started with writer->start , then its body is written with writer->write . Errors before start are answered with status 500 by the application.

Parameters
appthe application
requestthe request
writerthe response writer
Returns
0 when response is complete, -1 when response has been interrupted after its start (the connection has to be closed) ; a response which has not been started is answered with 500
