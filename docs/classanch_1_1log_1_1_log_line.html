Detailed Description

Log line.
Returned for levels greater or equal to MIN_LEVEL . The logger level is checked once at construction: when level is disabled, values are not formatted.
The message is written when the line is destroyed, i.e. at the end of the full expression.

A formatting error drops the message. Logging never throws.

Line is neither copyable nor movable. It must not be kept by reference: auto& line = LOG << anch::log::lvl::debug; is a dangling reference.
