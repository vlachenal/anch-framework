int(*) anch_rest_response_writer_t::start(void *ctx, unsigned int status, const anch_rest_header_t *headers, size_t headers_count, long long content_length)

Start response: send status and headers. It has to be called once, before write . Memory is copied by the module: it can be released after the call.
