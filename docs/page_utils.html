AnCH utils library documentation

Introduction

AnCH utils is a header only library of general purpose utilities, used by the other AnCH libraries.

Prerequisites

None.

Installation

CMake target anch::utils (header only):

find_package(Anch REQUIRED)
target_link_libraries(my-app PRIVATE anch::utils)

See installation.

Content

  • convert (convert.hpp ): strict string to number conversion (std::from_chars ).
  • ThreadPool (threadPool.hpp ): fixed number of persistent workers which execute queued tasks.
  • ResourcePool (resourcePool.hpp ): pool of resources (connections, ...) borrowed with RAII and validated when they are returned.
  • Singleton (singleton.hpp ): Meyers' singleton base class.
  • Flux , Fluent , collectors.hpp : streaming and fluent collection processing.
  • endianness.hpp , stringUtils.hpp , lessPtrCompare.hpp , optional.hpp : small helpers.

Example

#include "convert.hpp"
#include "threadPool.hpp"
#include <atomic>
#include <chrono>
#include <iostream>
int
main() {
// Strict number conversion (std::invalid_argument or std::out_of_range on error)
int value = anch::convert<int>("42");
double ratio = anch::convert<double>("0.5");
// Thread pool: tasks are executed by persistent workers
std::atomic<int> sum = 0;
anch::ThreadPool pool(4);
pool.start();
for(int i = 1 ; i <= 10 ; ++i) {
pool.add([&sum](int n) { sum += n; }, i);
}
pool.awaitTermination(std::chrono::seconds(0)); // waits for queued tasks (0: no timeout), then stops
std::cout << value * ratio << " " << sum << std::endl;
return 0;
}
