void anch::json::registerFormat ( const std::string & name,
anch::json::FormatValidator validator )

Register format validator (thread safe). It replaces the validator already registered with this name.
Registered formats:

  • email : dot-atom local part (64 characters at most) and host name domain (no quoted local part nor address literal) ;
  • hostname : RFC 1123 host name (labels of 63 characters at most, 253 characters at most) ;
  • ipv4 and ipv6 : inet_pton (no leading zero in IPv4 addresses, no IPv6 zone) ;
  • uri : RFC 3986 scheme followed by URI characters (percent encoding is checked, not the URI structure) ;
  • byte : base64 with padding (RFC 4648) ;
  • uuid (with ANCH_UUID ), date-time and date (with ANCH_DATE , RFC 3339, anch-date range: years 1678 to 2261 for date-time ).

void anch::json::setPatternCompiler ( anch::json::PatternCompiler compiler)

Set the pattern compiler used by anch::json::pattern . The default compiler uses std::regex (ECMAScript grammar) and std::regex_search . Another engine (RE2, PCRE2, ...) can be used for performance or for UTF-8 support: std::regex works on bytes ( . matches one byte, character classes do not contain multi-bytes characters).
The compiler is used when patterns are built: it has to be set before mappers registration (mappers are registered on their first use).

◆ validate()

template<typename T>
std::vector< anch::json::Violation > anch::json::validate ( const T & value)

Validate value: check every field constraint of the value and of its nested values (objects, collections items, maps values, std::optional and pointers values) without serializing it.
Unlike serialization and deserialization checks, validation does not stop on the first violation: every violation is returned. Constraints are checked whatever the mapping options are.

Only fields which can be read are checked (fields registered with a member or a getter, not with a setter only). Required fields are not checked: an object always has its fields ( std::optional and pointers can be empty when they are required and nullable).

for(const anch::json::Violation& violation : anch::json::validate(pet)) {
std::cout << violation.path << ": " << violation.message << std::endl;
}
