Detailed Description

Date string formatter and parser

Patterns are:

  • %Y: 4 digits year
  • %y: 2 digits year (parsed as 1969-2068 like strptime )
  • %m: month (01-12)
  • %d: day in month (01-31)
  • %H: hours (00-23)
  • %h: hours (01-12, like strptime %I ; 12 for noon and midnight)
  • %p: a.m./p.m. marker
  • %M: minutes (00-59)
  • %S: seconds (00-60)
  • %s: milliseconds (000-999)

Other characters, and unknown patterns, are written as is. Other patterns can be registered with registerFormatterPart .
Parsing requires every field to have its exact size (no sign, no space) ; fields which are not in the pattern are set to 1970-01-01 00:00:00.000 local time ; impossible dates (2025-02-30 for example) are refused.
format and parse can be called concurrently. Formatter parts have to be registered before formatters which use them are built.
