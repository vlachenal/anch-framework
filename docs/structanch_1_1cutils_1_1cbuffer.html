Detailed Description

C buffer.

Read and write functions return the number of bytes which have been read or written:

  • read: 0 means end of stream ;
  • write: it can write less bytes than requested (it is called again with the remaining bytes) ; 0 means error.

They can throw exceptions: the stream sets its badbit (and rethrows according to its exceptions mask).

data is optional: when NULL , it will be allocated/deallocated by CStreambuf. When set, it has to contain at least size bytes and to outlive the stream. In input-output mode, it is used for reading and a writing area of size bytes is allocated.
