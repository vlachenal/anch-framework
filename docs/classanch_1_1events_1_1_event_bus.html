Detailed Description

template<typename T>
class anch::events::EventBus< T >

A class which manage global events firing and events QoS.

Events are queued and notified asynchronously, in their firing order, by a dedicated thread (started on first event). fireEvent does not wait for observers: observers can fire events from their handle method.
Observers can add or remove observers from their handle method. When removeObserver returns, the observer will not be notified anymore and can be destroyed.

getInstance returns the global EventBus. Other buses can be created as plain objects.
The destructor notifies the queued events and stops the thread: it must not be called from an observer. The global bus is destroyed at program exit: its observers must not use already destroyed static objects.
