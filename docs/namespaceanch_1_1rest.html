Detailed Description

AnCH REST library namespace.

It contains the HTTP model (Request, Response, ...), codecs, the server API declaration (Api) and the HTTP client (Client). See AnCH REST library documentation.

Select the best available media type for Accept media ranges (RFC 9110 proactive negotiation): the quality of an available media type is the quality of the most specific media range which includes it. On equal quality, the first available media type is selected.
