Detailed Description

AnCH REST library namespace.

It contains the HTTP model (Request, Response, ...), codecs, the server API declaration (Api) and the HTTP client (Client). See AnCH REST library documentation.

◆ installRpc()

void anch::rest::installRpc ( anch::rest::Api & api,
const anch::rest::RpcService & service,
std::string_view prefix = std::string_view() )

Install RPC service methods in API (header only: link anch::rest-server ): one POST [prefix]/package.Service/Method route per method, which serves:

  • Connect unary calls: application/proto (or application/x-protobuf ) and application/json bodies, 200 with the response message or Connect error ( {"code":"not_found","message":"..."} with the HTTP status of the code) ;
  • gRPC-Web unary calls: application/grpc-web , application/grpc-web+proto and application/grpc-web+json bodies (message frame), 200 with the response message frame and the trailers frame ( grpc-status , grpc-message ). Other content types are refused ( 415 ). Response metadata are HTTP headers. API filters and CORS apply (gRPC-Web browser clients need grpc-status and grpc-message exposed headers).
Parameters
apithe API
servicethe service (it has to outlive the API)
prefixthe routes prefix ( /rpc , empty by default)

◆ installThrift()

void anch::rest::installThrift ( anch::rest::Api & api,
std::string_view path,
std::shared_ptr< apache::thrift::TProcessor > processor,
std::size_t maxMessageSize = 16 *1024 *1024 )

Install Thrift service in API (header only: link anch::rest-server ): POST path processes Thrift messages with the processor generated by thrift –gen cpp , as Thrift THttpServer . The protocol is chosen with the request Content-Type ( application/x-thrift and application/vnd.apache.thrift.binary , .compact , .json ), the response has the same content type. Declared exceptions and unknown methods are answered by the processor (Thrift application exceptions), unsupported content types with 415 , invalid messages with 400 .

auto handler = std::make_shared<PetStoreHandler>(); // implements generated PetStoreIf
anch::rest::installThrift(api, "/thrift/pets", std::make_shared<pets::PetStoreProcessor>(handler));
