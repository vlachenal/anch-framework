Detailed Description

TCP connection as a std::iostream.

Written data are buffered: they are sent when the buffer is full, on flush (or std::endl ), before reading (request / response protocols do not need an explicit flush) and on destruction.
End of stream (eof ) is reached when the peer has closed the connection (or shut down its transmission). Network errors set badbit ; with exceptions(std::ios::badbit) , the IOException is raised.
TcpStream can not be copied nor moved: it is built from a host and a port (client) or from a connected Socket (TcpServer::accept ).

anch::network::TcpServer server("", 40099);
anch::network::TcpStream client("localhost", 40099);
anch::network::TcpStream peer = server.accept();
client << "hello" << std::endl;
std::string line;
std::getline(peer, line);
