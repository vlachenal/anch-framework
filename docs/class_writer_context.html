void anch::json::WriterContext::writeEscaped ( std::string_view str)

Write characters escaped according to RFC 8259 (without '"' around): '"', '\' and control characters (\b, \f, \n, \r, \t, \u00XX for the others). Other characters (UTF-8 included) are written as is.
